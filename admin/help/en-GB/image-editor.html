Adding images and image details

Events, venues and categories can show an image with its own description and credit. An event has two image slots: the intro image for lists and cards, and an optional full image for its detail page. Edit each slot separately.

1. Choose the image

  1. In the backend, open the record's Image tab. In the frontend, open its image section.
  2. To reuse an image already on the server, click Select Image in the backend or choose it from the searchable Server image list in the frontend.
  3. To add a file from your computer, click Upload in the backend or use Upload new image in the frontend. Choose a server image or a new upload for each slot, not both.
  4. Check the image preview, then save the record. The folder shown beside the selector tells you where JEM looks for images; it is not a box in which you must type the image's full file path.

JEM applies its configured image-processing rules to new uploads. Selecting an existing server image does not require uploading it again.

2. Add the image details

Alternative text is a short description for accessibility. It is not the place for a copyright notice. In the Advanced JEM profile, open Caption and credit beneath that image if it is collapsed:

  • Caption: describe what the image shows. Bold, italic and text colour are available.
  • Photo credit / licence: enter the photographer, source or licence. Select text and click the link button if you want to link to a source or licence page. In the link dialog, Open link in... defaults to New tab; change it for that link if needed.
  • Credit label: choose a short prefix such as Photo, Credits, Source or Copyright. Choose None for unlabelled text, or Custom for your own prefix.
  • Credit position: show it below the image or at the bottom of the event, venue or category section. “Bottom of section” does not mean the website footer.

Save and inspect the public detail page. The caption and credit are shown with the detail image; the credit can appear below the image without opening it. List thumbnails do not show these details. If you replace an image, check and update its description and credit for the new picture. Clear removes the selected image and resets its image details.

If the Caption and credit controls are unavailable, ask the site administrator whether JEM's Advanced profile is enabled.
